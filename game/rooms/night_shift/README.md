# Night Shift

Prototype room (PLAN.md Section 10). 60 minutes, 1-4 players. **Status: M1 greybox** - primitive geometry only, fully playable start to win. Art and the real intranet CTF container arrive in M3/M4.

## Play-test

```bash
# dev mode (room loaded straight from res://rooms/night_shift/)
godot --path game -- --room night_shift

# validate the manifest and regenerate room.json after editing room.yaml
go run ./tools/roomcheck -write-json game/rooms/night_shift

# headless replay of the solution (the M1 acceptance test)
GODOT_BIN=$(readlink -f ~/.local/bin/godot) bash game/addons/gdUnit4/runtest.sh \
  --path game --headless --ignoreHeadlessMode -a res://tests/rooms

# export the pack and replay the solution from the pack alone
go run ./tools/packroom -verify night_shift
```

Offline (M1) the laptop's flag field accepts any non-empty value (`DevFlagValidator`); the real per-session flag check arrives with the platform in M3.

## Puzzle chart

```
 [find_uv] desk drawer -> UV torch
     |
 [open_cabinet] UV whiteboard -> {{cabinet_code}} -> filing cabinet
     |   (network diagram, USB stick)
     |
     |      [hack_intranet] sticky note (mreyes) + WiFi card back (password)
     |          -> laptop connection card -> intranet IDOR -> flag
     |          -> FlagGate releases cage maglock
     |               |
     +------> [restore_power] patch panel P1 per diagram (A3 B7 C1 D5)
                     -> UPS powers the exit override panel
                          |
   fire certificate (SITE 417) + rack stencil (RACK 062)
                          |
               [override_door] 417062 on the exit panel -> WIN
```

| Puzzle | Requires | Solved when |
|---|---|---|
| `find_uv` | - | `uv_torch` picked up |
| `open_cabinet` | find_uv | `Office/FilingCabinet/Keypad` unlocked |
| `hack_intranet` | - | flag `intranet` accepted |
| `restore_power` | hack_intranet, open_cabinet | `Cage/PatchPanel` solved |
| `override_door` (exit) | restore_power | `Office/ExitDoor/Keypad` unlocked |

## Greybox notes

- The scene was generated by a throwaway script; edit `room.tscn` in the Godot editor from here on.
- Colour key: torch purple, sticky note yellow, laptop blue-grey, WiFi card light blue, certificate red-bordered cream, filing cabinet olive, network diagram cyan, USB stick orange, cage door yellow mesh, maglock dark red, patch panel light grey with coloured cable tags.
- Decor (not interactable, rule 3): desk, chair, monitor, papers in the drawer, whiteboard board, pinboard, server rack, UPS.
- The cage wall is semi-transparent so the rack and its stencil are visible from the office before the cage opens.
